# SpecIal (stage 1)

Fabric client mod, Minecraft 1.21.11, Java 21.

Contents: HUD (Watermark, Info, Effects, Armor, Keystrokes), menu (Right Shift),
HUD Editor (drag blocks), Login button in Multiplayer (offline accounts).

Build: put these files into a project created from the official Fabric template
(https://fabricmc.net/develop/template/, MC 1.21.11, Yarn), or run `gradle wrapper`
then `./gradlew build`. The jar appears in build/libs/.
